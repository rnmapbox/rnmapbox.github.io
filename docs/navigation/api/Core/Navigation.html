Navigation

const Navigation: object;

The headless navigation API: route requests, the app's single guidance session, and its events. It's also the default export.

setCameraState()​

setCameraState(state: CameraState): void;

Camera of every navigation map (<MapView mapViewImpl={NAVIGATION_MAP_VIEW_IMPL}>). idle hands the camera back to the user's gestures and @rnmapbox/maps Camera. Guidance switches it to following; a pan, zoom, rotate or pitch gesture on any navigation map switches it to idle. Use addCameraStateListener to follow those changes.

Parameters​

ParameterType
stateCameraState

Returns​

startActiveGuidance()​

startActiveGuidance(route: Route, options?: StartActiveGuidanceOptions): Promise<void>;

Starts active guidance along route, replacing any active guidance, and switches the camera to following. Rejects if route was released. Guidance keeps its own reference to the native route until stopNavigation, so route can be released at any time.

Parameters​

ParameterType
routeRoute
options?StartActiveGuidanceOptions

Returns​

Promise<void>

stopNavigation()​

stopNavigation(): void;

Stops guidance and removes the route from navigation maps. The camera switches to idle and eases back to north-up.
