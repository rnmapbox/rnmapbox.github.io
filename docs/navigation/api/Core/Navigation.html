requestMatchedRoutes()​

requestMatchedRoutes(options: MatchedRouteRequestOptions): Promise<RouteResponse>;

Snaps options.coordinates to roads with the Mapbox Map Matching API and resolves with a route along them, for guiding a path the app defines, such as a tour or a delivery run. The route works with previewRoute and startActiveGuidance like one from requestRoutes; alternatives is always empty. Neither SDK reroutes a matched route: guidance reports going off route and waits for the user to return to it.

Rejects without a request if the options break the Map Matching API's limits, and with code: 'no_single_match' if the API can only match the coordinates as several disconnected pieces. On Android this uses requestMapMatching, which the SDK marks @ExperimentalPreviewMapboxNavigationAPI, so it may change in minor releases.

Parameters​

ParameterType
optionsMatchedRouteRequestOptions

Returns​

Promise<RouteResponse>

setRerouteEnabled()​

setRerouteEnabled(enabled: boolean): void;

Whether guidance requests a new route when the user leaves a route from requestRoutes. Defaults to true. Matched routes from requestMatchedRoutes are never rerouted.

Android applies it at once, also during guidance. iOS reads it only when the navigation session is created, which happens on the first route request or guidance start, so call it before those, e.g. next to setAccessToken. On iOS a later call that changes the value has no effect and logs a warning.

setSimulationSpeed()​

setSimulationSpeed(multiplier: number): void;

Speed of simulated guidance relative to the route's expected speeds, e.g. 2 drives twice as fast; the default is 1. Applies to the running and later simulations. startFreeDrive()​

startFreeDrive(options?: StartFreeDriveOptions): Promise<void>;

Starts free drive: the location is matched to the road without a route, so addLocationListener reports the road name and speed limit, and navigation maps show the puck. It runs until stopNavigation or a JS reload; this API never starts it on its own.

During guidance it ends the guidance and keeps the session in free drive. After simulated guidance, the simulated device stays where guidance stopped unless simulatedLocation moves it.

Free drive trips are billed by Mapbox like guidance trips, see Navigation SDK pricing.

Rejects with code: 'location_permission' if the app has no location permission and simulatedLocation isn't set; request the permission first.

Parameters​

ParameterType
options?StartFreeDriveOptions

Returns​

Promise<void>
