MapView

import { MapView } from '@rnmapbox/maps';

MapView

MapView renders an interactive Mapbox map in a React Native app on iOS and Android. It is the root component of a map: add a Camera, sources, layers, annotations and the user location as its children.

props​

contentInset​

number | number[]

The distance from the edges of the map view’s frame to the edges of the map view’s logical viewport. @deprecated use Camera padding instead

projection​

'mercator' | 'globe'

The projection used when rendering the map

Globe Projection

styleURL​

string

Style URL for map - notice, if non is set it will default to Mapbox.StyleURL.Street

styleJSON​

string

StyleJSON for map - according to TileJSON specs: https://github.com/mapbox/tilejson-spec

preferredFramesPerSecond​

number

iOS: The preferred frame rate at which the map view is rendered. The default value for this property is MGLMapViewPreferredFramesPerSecondDefault, which will adaptively set the preferred frame rate based on the capability of the user’s device to maintain a smooth experience. This property can be set to arbitrary integer values.

Android: The maximum frame rate at which the map view is rendered, but it can't exceed the ability of device hardware. This property can be set to arbitrary integer values.

attributionEnabled​

boolean

The Mapbox terms of service, which governs the use of Mapbox-hosted vector tiles and styles, requires these copyright notices to accompany any map that features Mapbox-designed styles, OpenStreetMap data, or other Mapbox data such as satellite or terrain data. If that applies to this map view, do not hide this view or remove any notices from it.

You are additionally required to provide users with the option to disable anonymous usage and location sharing (telemetry). If this view is hidden, you must implement this setting elsewhere in your app. See our website for Android and iOS for implementation details.

Enable/Disable attribution on map. For iOS you need to add MGLMapboxMetricsEnabledSettingShownInApp=YES to your Info.plist

defaults to: true Ornaments

Adds attribution offset, e.g. {top: 8, left: 8} will put attribution button in top-left corner of the map. By default on Android, the attribution with information icon (i) will be on the bottom left, while on iOS the mapbox logo will be on bottom left with information icon (i) on bottom right. surfaceView​

boolean

[Android only] Enable/Disable use of GLSurfaceView instead of TextureView. Defaults to true, or to false when transparent is set. Only applies when the map is created.

transparent​

boolean

Renders the map with a transparent background, so views behind the map show through wherever the style's background is transparent or semi-transparent. The style must provide that background itself, e.g. a background layer with background-color: rgba(0,0,0,0); maps with regular Mapbox styles stay opaque. Snapshots taken with takeSnap keep the transparency.

On Android this uses a TextureView, which is slower, uses more memory and lags one frame behind the rest of the UI. It only applies when the map is created and overrides surfaceView={true}.

Globe fog and atmosphere may not composite correctly over a transparent background.

Transparent Map

localizeLabels​

| {
    /** locale code like `es` or `current` for the device's current locale */
    locale: string;
    /** layer ids to localize. If not specified, all layers will be localized */
    layerIds?: string[];
  }
| true

Set map's label locale, e.g. { "locale": "es" } will localize labels to Spanish, { "locale": "current" } will localize labels to system locale. Labels are localized on the device for this map only, into ar, de, en, es, fr, it, ja, ko, pt, ru, vi, zh-Hans or zh-Hant, and not on the Standard style. For any language Mapbox supports and for the Standard style, use the app-wide Mapbox.setLanguage. Removing the prop stops localizing labels from the next style load.

Localize Labels

symbolScaleBehavior​

'system' | { fixed: number }

How map symbols (icons and text) scale with the system text size setting. 'system' follows the device's text size, from 0.8x up to 2.0x for accessibility sizes. { fixed: number } uses a constant scale factor, recommended range 0.8–2.0. Defaults to { fixed: 1.0 }.

@experimental Uses an experimental Mapbox API that may change in a future SDK release.

Symbol Scale Behavior

styleGlyphURL​

string

Overrides the glyph URL of the style, so labels use fonts from another glyph server, e.g. https://example.com/fonts/{fontstack}/{range}.pbf. It is re-applied on every style load. Removing the prop restores the style's own glyphs from the next style load.

@experimental Uses an experimental Mapbox API that may change in a future SDK release.

queryRenderedFeaturesAtPoint(coordinate[, filter][, layerIDs])​

Returns an array of rendered map features that intersect with a given point.

arguments​

NameTypeRequiredDescription
coordinatePositionYesA point expressed in the map view’s coordinate system [x, y];
filterFilterExpression | tupleNoA set of strings that correspond to the names of layers defined in the current style. Only the features contained in these layers are included in the returned array.
layerIDsArrayNoA array of layer IDs by which to filter the features.
const x = 30; const y = 40;
this._map.queryRenderedFeaturesAtPoint([x, y], ['==', 'type', 'Point'], ['id1', 'id2'])

Screen Coordinates### queryRenderedFeaturesInRect(bbox[, filter][, layerIDs])

Returns an array of rendered map features that intersect with the given rectangle,
restricted to the given style layers and filtered by the given predicate. In v10,
passing an empty array will query the entire visible bounds of the map.

arguments​

NameTypeRequiredDescription
bboxBBox | []YesA rectangle expressed in density-independent screen coordinates relative to the map view [top, left, bottom, right] or [minY, minX, maxY, maxX] (not geographic coordinates). An empty array queries the visible map area.
filterFilterExpressionNoAn array of strings that correspond to the names of layers defined in the current style. Only the features contained in these layers are included in the returned array.
layerIDsArrayNoA array of layer IDs by which to filter the features.
const left = 40; const top = 30;
const right = 10; const bottom = 20;
this._map.queryRenderedFeaturesInRect([top, left, bottom, right], ['==', 'type', 'Point'], ['id1', 'id2'])

Screen Coordinates### querySourceFeatures(sourceId[, filter][, sourceLayerIDs])

Returns an array of GeoJSON Feature objects representing features within the specified vector tile or GeoJSON source that satisfy the query parameters.

arguments​

NameTypeRequiredDescription
sourceIdstringYesStyle source identifier used to query for source features.
filterFilterExpression | tupleNoA filter to limit query results.
sourceLayerIDsArrayNoThe name of the source layers to query. For vector tile sources, this parameter is required. For GeoJSON sources, it is ignored.
this._map.querySourceFeatures('your-source-id', [], ['your-source-layer'])
